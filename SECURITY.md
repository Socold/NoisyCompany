# Security policy

Please report vulnerabilities privately through GitHub's
"Report a vulnerability" button (Security tab of this repository). Do not open a public
issue. We aim to answer within 7 days.

In scope: anything that makes NoisyCompany fetch content it should not (blocked URLs, ads,
non-HTML payloads beyond the size cap), exceed its budget, leak local data in requests,
or run code from fetched content. NoisyCompany never executes fetched content.
