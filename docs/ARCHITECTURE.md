# Architecture

```
                 +-------------------- noisycompany run -------------------+
config.toml ---> | config  ->  Engine (scheduler, budget, pacing, gates)   |
features.json -> | features    |-- personas / packs / collective (who)   |
                 |             |-- dns / doh            (DNS noise)      |
                 |             |-- web.Fetcher          (HTTP noise)     |
                 |             |     url_allowed: scheme, scope, public IP|
                 |             |     scoped redirects, size + inflate caps|
                 |             |     sockets pinned to the vetted IP     |
                 |             |-- netwatch / metered   (back-off)       |
                 |             |-- label()  -> labelled.jsonl            |
                 |             '-- server.LocalServer  127.0.0.1 only    |
                 |                   dashboard :9788 (token, CSP, Host)  |
                 |                   metrics   :9789                     |
                 +---------------------------------------------------------+
companion/ (Firefox MV3): lib.js (pure logic) + background.js (alarms, idle, fetch|tab)
                          personas.js + manifest.json generated by `companion export`
```

## Modules (`src/noisycompany/`)

| Module | Role |
|---|---|
| `cli.py` | Commands: run, estimate, features, privacy, packs, collective, companion, study, benchmark, energy, scenario, health, personas, config |
| `config.py` | Defaults, presets (eco/balanced/max), validation, persona loading |
| `engine.py` | Main loop: active hours, exponential gaps, budget pacing, netwatch, sessions, labelled log, heartbeat, feature refresh between sessions |
| `budget.py` | Daily byte cap, hourly action cap |
| `features.py` | Registry of every roadmap item and its switch, runtime overrides |
| `personas.py` | Salted rotation, persona drift |
| `rhythm.py` | Weekday / weekend / holiday / season activity factor (`weekly_rhythm`) |
| `packs.py` | Reviewed packs, business profiles, validator (sensitive topics, https, scope) |
| `collective.py` | Share codes (`nc1:`), digest, reviewed personas only |
| `dns.py` / `doh.py` | System-resolver lookups / RFC 8484 DoH |
| `web.py` | Polite fetcher: robots.txt, per-host delay, size caps, public-IP and scope checks, request trees |
| `netwatch.py` / `metered.py` | Back-off on user traffic / metered links |
| `impact.py` | Bandwidth and energy estimate |
| `privacy.py` | Local privacy report |
| `qr.py` | Stdlib QR encoder for share codes (terminal, SVG) |
| `benchmark.py` | Offline benchmark: real engine, simulated clock, fake network, synthetic household |
| `energy.py` | CPU time and RAPL energy per session |
| `scenarios.py` | SOC scenarios: labelled benign traffic offline, with checks |
| `study.py` | Separability study (windows, logistic regression, ROC AUC) |
| `companion.py` | Generates the extension's personas and manifest |
| `server.py` | Localhost dashboard and Prometheus metrics |
| `data/` | Default config, personas, packs, business profiles, dashboard assets |

## Deployment (`deploy/`)

`homeassistant/`, `raspberrypi/`, `systemd/`, `openwrt/` (init script and SDK packages),
`pihole/`, `apps/` (Umbrel, CasaOS, TrueNAS, Unraid), `grafana/`. All use the same image
or sources, the eco preset and no published port.

## Design rules

- **Zero runtime dependency** (stdlib only); the companion has none either.
- **Everything new is a switch**, off by default, and must update `estimate` if it
  costs bandwidth.
- **Nothing executes fetched content**; HTML is only scanned for links.
- **Single source for personas**: TOML in `data/`, validated in CI, exported to the
  companion.

## Tests

`pytest` (Python 3.11-3.13 in CI) and `node --test` for the companion, plus the Mozilla
add-on linter, `ruff`, pack validation and a stale-files check for the companion.
